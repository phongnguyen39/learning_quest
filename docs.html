Help & Guide

Everything you need to know — for kids, parents, and using it offline.

Getting started

  1. When you open the app, you'll see "Who's Playing?" — tap your name, or tap + Add New if it's your first time.
  2. Pick a name and an avatar (your little icon). Tap Start Adventure.
  3. You'll land on the Home screen — this is your home base.

Practicing (Number Realm & Word Realm)

Tap Number Realm for math topics or Word Realm for reading topics. Pick any topic you want to practice — you'll get a short set of questions. Answer them, get instant feedback, and earn stars for correct answers and streaks.

You can practice any unlocked topic as many times as you want — it's just for fun and getting better, no pressure.

🎓 Learning Path (the main program)

This is the structured, week-by-week program. Tap Math Path or Reading Path from the Home screen.

Each week is one topic (a "unit"), and each unit has a rhythm:

  • 📺 Watch — a video that teaches the topic properly, not just a quick recap
  • 📝 Practice — a couple of practice rounds on that topic
  • 🎯 Unit Test — a bigger, 12-question test. Score at least 75% to pass
Units unlock in order. You have to pass a unit's test before the next week's unit unlocks. If you don't pass, that's totally fine — go back and practice more, then retake the test whenever you're ready.

Switching players

If someone else wants to play (a sibling, for example), tap your avatar circle at the top of any screen — it takes you back to "Who's Playing?" so someone else can pick their name.

Stars, badges, and progress

You earn stars for correct answers, and bonus stars for answer streaks and passing unit tests. Keep an eye out for badges too — they show up when you hit certain milestones.

Accessing the dashboard

Go to admin.html (or tap "Administrator Access" at the bottom of the Home screen in the main app). Enter the admin password to get in.

The current password is a placeholder. If you haven't changed it yet, it's worth doing before sharing the app link with anyone outside your household — see "Changing the password" below.

What you'll see

🔥 Recurring Challenges

This panel looks across every student who has taken a unit test, and surfaces which topics people are struggling with the most — sorted by pass rate, worst first. If several kids are stuck on the same topic, that's usually a sign the video or practice content for that unit needs another look, rather than any one kid having trouble.

Students list

Every student who has played on any device shows up here (as long as they're online at some point — see Offline Mode), along with:

  • Grade level
  • Units mastered out of total units attempted
  • Total practice sessions played
  • Their single weakest unit (lowest test score), if they've taken any unit tests

How data gets here

Every device syncs in the background to your own Learning Quest server (a small program running on your home computer, reached over the internet through an ngrok tunnel). This means a student can practice on a tablet, a laptop, and a phone, and all their progress ends up in the same place — you're not looking at just one device's data.

Sync happens automatically after every practice session and unit test. It's "fire and forget" — if a device is offline, nothing breaks, it just catches up next time it's back online.

Changing the admin password

The password lives in admin.html as a constant near the top of the file:

const ADMIN_PASSWORD = "test";

Change the text between the quotes to whatever you want, save the file, and push/redeploy — same process as any other app update.

This is a simple shared password, not a full login system — good enough for a family setup, but not meant to hold up against someone determined to guess it. Don't reuse a password you use elsewhere.

Managing students

There's no separate "delete student" button yet — students are created the first time a name is entered on a device. If you need to remove or rename someone, that currently requires a direct edit in the server's SQLite database (the students table) or clearing local storage on that device before it's ever synced.

What works without internet

  • Playing quizzes and unit tests — fully works offline. Questions are generated locally, no internet needed.
  • Your progress, stars, and badges — saved on the device itself (not just the cloud), so nothing is lost if you're offline.
  • Opening the app itself — once you've opened it at least once with internet, the app can load again later even with zero signal (see "Installing" below).

What needs internet

  • Syncing to your server — so progress shows up on the Admin Dashboard and on other devices. This happens automatically the next time there's a connection; nothing needs to be done manually.
  • The Admin Dashboard itself — it always pulls live data, so it needs a connection to show anything.
  • Watching the "Learning Path" intro videos — these are YouTube links, which need internet to actually play.

📲 Installing the app for offline use

For the best offline experience, install the app to the home screen instead of just using it in a browser tab:

On a phone or tablet (iOS or Android)

  1. Open the app link in the browser (Safari on iOS, Chrome on Android) while you have internet.
  2. iOS: tap the Share icon → "Add to Home Screen".
  3. Android: tap the menu (⋮) → "Add to Home Screen" or "Install app".
  4. Open it from the home screen icon from now on — it'll behave like a regular app, and will keep working even with no signal.

On a computer

  1. Open the app in Chrome or Edge.
  2. Look for an install icon in the address bar (or menu → "Install Learning Quest").
  3. It'll open in its own window from then on, separate from the browser.
You only need to do this once per device, and you need internet the first time so the app can save a copy of itself. After that, it'll open fine with no connection at all.

Good to know

If you make big changes offline across multiple devices before ever syncing (e.g., two devices both play for days with no internet), the most recent sync per topic/unit generally wins — it's not built to intelligently merge conflicting offline histories. For most families playing on one or two regularly-connected devices, this isn't something you'll ever run into.
